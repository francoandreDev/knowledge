---
title: "L1 — What actually makes an argument valid vs. just convincing?"
---

- **Validity** is a structural property: an argument is valid if its conclusion _must_ be true whenever its premises are true — regardless of whether the premises actually are true in reality.
- **Soundness** = valid structure + true premises. A valid argument with a false premise is still valid, just not sound — and it's the false premise that's the actual problem, not the logic.
- **Persuasiveness is a completely separate axis from validity.** An argument can be maximally convincing (confident delivery, emotional resonance, social proof) while being structurally invalid — and vice versa: a tight, valid, sound argument can still fail to persuade if delivered badly.
- **Formal logic** studies argument structure independent of content — the same invalid pattern ("affirming the consequent," etc.) is invalid no matter what real-world claims you plug into it.
- **Informal logic** studies arguments as they actually occur in language: ambiguity, unstated assumptions, rhetorical tricks that formal structure alone doesn't catch.
- The core engineering skill this unit builds: separating "is this structurally sound" from "does this feel true" — because engineering decisions get sold with confident, structurally-broken arguments constantly, and being able to name _why_ an argument fails (not just that it feels off) is what lets you push back credibly.
- Two premises, one conclusion, one structure — that's the smallest unit of analysis. Most real arguments are chains of these, and the chain is only as strong as its weakest link.
