You own a $300 bike and park it outside. Without a lock, you guess a 5% chance
it is stolen this year. A cheap $8 padlock, you guess, cuts that to 1%. Those
percentages are assumptions, not measurements. Your gut says "5% is small, why
bother" one minute and "losing $300 would be awful" the next. **How do you
compare "spend $8 for certain" against "maybe lose $300"
when one is a sure cost and the other is a chance?**

Put both on the same axis: what each choice costs you _on average_. No lock:
0.05 x $300 = **$15**. Padlock: $8 + 0.01 x $300 = **$11**. The lock is
worth about $4 a year in this made-up case. The arithmetic does not remove the
uncertainty, it just stops the argument from going in circles.

</Scenario>

The padlock was never "safe" versus "unsafe". Both options carry risk. The
number that settles it weighs how likely a loss is against how large it is.

## How do you weigh a chance against an amount?

**Expected value (EV)** is the average result of a risky choice if you could
repeat it many times: each possible outcome counts in proportion to how often
it happens.

$$
EV = \sum_i p_i v_i
$$

where the probabilities satisfy

$$
\sum_i p_i = 1
$$

Each outcome has a probability $$p_i$$ and a value $$v_i$$ (a cost is
negative). Now the same rule on an engineering decision. A team can run a
risky database migration today, or wait three weeks for a maintenance window.
All figures are the unit's assumptions, not data.

| Option          | If it goes wrong               | If it goes fine             |
| --------------- | ------------------------------ | --------------------------- |
| Migrate now     | 15% chance of a $50,000 outage | 85% chance of $8,000 gained |
| Wait for window | 2% chance of the same outage   | 98% chance of $5,000 gained |

| Option          | Calculation                         | Expected value |
| --------------- | ----------------------------------- | -------------- |
| Migrate now     | `0.15 × (−$50,000) + 0.85 × $8,000` | **−$700**      |
| Wait for window | `0.02 × (−$50,000) + 0.98 × $5,000` | **+$3,900**    |

Waiting is worth $4,600 more on average. Gut feeling said "2% is obviously
safer", which is true but incomplete: the comparison needs the payoffs too.

## What is an expected value not?

**If migrating now has an EV of −$700, will today's migration lose $700?** No.
It ends either at +$8,000 or at −$50,000. The −$700 describes the long-run
average over many similar bets, a number the single attempt never lands on.

## Key terms

- **Outcome** — one possible result; the outcomes of a decision must cover
  every case and not overlap.
- **Probability** — how likely an outcome is, between 0 and 1; all of a
  decision's probabilities add to 1.
- **Value** — what an outcome is worth in one common unit (dollars, hours,
  users). Losses are negative.
- **Expected value** — the probability-weighted average of the values.
- **Estimate** — every probability here is a guess; the arithmetic is exact,
  the inputs are not.
