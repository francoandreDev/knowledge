## What does cosine similarity measure that distance misses?

**The dot product of two vectors is large when they point the same way. How do
you turn it into a score that ignores how big the vectors are?** Divide by both
lengths. For Ana `(5, 4)` and Cleo `(1, 5)`:

- Dot product: `5·1 + 4·5 = 25`
- Lengths: `√41 ≈ 6.40` and `√26 ≈ 5.10`
- Cosine similarity: `25 / (6.40 × 5.10) ≈ 0.766`

For Ana and Ben, `(4, 3.2)` is exactly 0.8 times `(5, 4)`, so they point the
same way and the score is 1, although the distance is about 1.28. The score
depends only on the angle between the vectors:

<Checkpoint question="A user who rated nothing has the vector (0, 0). What goes wrong when you compute cosine similarity against anyone?">

The denominator contains the length of `(0, 0)`, which is 0, so the formula
divides by zero and the similarity is undefined. A real system has to choose a
convention for that case (for example "no similarity") instead of letting it
crash or produce a meaningless number.

## How does the matrix-vector product look as code?

**The recipe matrix had 2 rows and 3 columns. What is the least code that
works for any shape?** One dot product per row:

```js
function matVec(matrix, v) {
  return matrix.map((row) => row.reduce((sum, a, i) => sum + a * v[i], 0));
}

matVec(
  [
    [1, 1],
    [1, 0],
  ],
  [3, 5],
); // [8, 3]
```

Composing two matrices follows the same pattern: each entry of `A·B` is a row of
`A` dotted with a column of `B`. Applying `A` after `B` to a vector gives the
same result as multiplying the matrices first, so `matVec(A, matVec(B, v))`
equals applying the combined matrix to `v`.

## Extend it: what changes when the case changes?

This unit followed one case: two 2-number vectors and a handful of 2×2 or 2×3
matrices. It is a case, not the whole territory. Try pushing it:

- What if there were 3 features per person (action, comedy, runtime)? Which
  functions change, and which formulas stay identical?
- Euclidean distance asks "how far apart", cosine asks "how aligned". For Ana
  and Cleo, which does each call more different, and would a different pair of
  people reverse the ranking?
- A 2×2 matrix cannot move a point (the origin always stays fixed). What extra
  coordinate would you add so that move, rotate and scale fit in one matrix?

## Failure modes

| Failure mode                                         | What goes wrong                                                           |
| ---------------------------------------------------- | ------------------------------------------------------------------------- |
| Reordering transforms assuming they commute          | Safe only for special pairs such as two uniform scales                    |
| Using distance to compare vectors of different scale | Mixes size with direction and ranks the wrong pair as similar             |
| Cosine similarity with an all-zero vector            | Divides by zero; the code must choose a convention                        |
| Matrix and vector shapes that do not match           | A row with 3 entries cannot dot a vector with 2; the product is undefined |
| Passing degrees to `Math.cos` or `Math.sin`          | They expect radians and silently return a wrong number                    |
