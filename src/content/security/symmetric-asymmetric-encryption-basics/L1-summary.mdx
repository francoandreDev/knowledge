Alice needs to send Bob a confidential contract by email. She encrypts
the file with a secret key so it's unreadable in transit, then emails
Bob the encrypted file. To let Bob decrypt it, she also has to send him
the key — so she emails that too, over the same network the first
email traveled. **The file itself is now genuinely unreadable to an
eavesdropper. Does that actually solve the problem?**

</Scenario>

## The shape of the problem

- Encrypting the file is only half the problem — the file is
  unreadable without the key, but the key itself now has to reach Bob
  somehow, and whatever channel carries the key is just as
  interceptable as the one that carried the file.
- This is the **key distribution problem**: with a single shared
  secret key, there's no way to get that key to the other party without
  either an already-secure channel (which defeats the purpose of
  needing encryption in the first place) or accepting the same
  interception risk twice.
- A different kind of encryption — using two mathematically related
  keys instead of one shared secret — makes it possible to send
  something encrypted to someone you've never securely communicated
  with before, without ever transmitting a secret at all.

## Key terms

- **Symmetric encryption** — the same single key both encrypts and
  decrypts; fast, but requires that key to somehow reach every party
  who needs it, securely.
- **Asymmetric encryption** — uses two mathematically related keys, a
  public one and a private one; anything encrypted with the public key
  can only be decrypted with the matching private key.
- **Public/private key pair** — the public key can be shared with
  anyone, openly, with no secrecy required; the private key must never
  leave its owner's possession.
- **Key distribution problem** — the challenge of getting a shared
  secret key to everyone who needs it, without exposing it to
  interception along the way — the specific problem asymmetric
  encryption is designed to solve.

## What this unit covers

L2 works through why asymmetric encryption solves the key distribution
problem, what it costs to get that benefit, and why real systems
combine both approaches rather than picking one. L3 demonstrates both
kinds of encryption with real, runnable code — including measuring
exactly how much slower asymmetric encryption is, and building the
hybrid approach that gets the best of both.
